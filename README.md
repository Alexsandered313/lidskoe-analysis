## О проекте

Лидское пиво — один из крупнейших пивоваренных заводов Беларуси, основан в 1876 году. Продуктовая линейка включает более 40 позиций, распределённых по нескольким регионам страны.

Задача: проанализировать продажи и дистрибуцию продуктовой линейки, выявить неэффективные SKU, оценить сезонность спроса и сформировать рекомендации для коммерческого отдела.

## Цели и задачи

- Оценить структуру продаж по категориям и регионам
- Выявить сезонные паттерны спроса
- Провести ABC-анализ SKU по выручке
- Определить регионы с низкой представленностью ключевых позиций
- Построить дашборд для коммерческого отдела

## Методология

**1. Предобработка данных**
- Очистка от дубликатов и пропущенных значений
- Приведение типов, нормализация наименований SKU
- Создание временных признаков: месяц, квартал, сезон

**2. Исследовательский анализ (EDA)**
- Распределение продаж по категориям: светлое / тёмное / безалкогольное / специальное
- Динамика выручки по месяцам за 2 года
- Тепловая карта продаж регион × SKU

**3. ABC-анализ**
- Группа A (топ 20% SKU) — формирует 78% выручки
- Группа B (следующие 30%) — 17% выручки
- Группа C (оставшиеся 50%) — 5% выручки → кандидаты на вывод из линейки

**4. Сезонный анализ**
- Пик продаж: май–август (+34% к среднемесячному уровню)
- Провал: декабрь–февраль (−22%)
- Выявлены SKU с контрсезонным поведением — точки для промо-активностей

**5. Региональный анализ**
- Минск и Минская область: 41% продаж
- Гродненская и Брестская области: недопредставленность 3 ключевых SKU группы A
- Рекомендация: расширить дистрибуцию в западных регионах

## Ключевые выводы

- **SKU группы C** составляют 50% ассортимента, но приносят только 5% выручки — сокращение линейки освободит складские мощности и упростит логистику
- **Сезонный провал** в зимние месяцы можно частично компенсировать продвижением тёмных и специальных сортов, спрос на которые менее выражен сезонно
- **Три региона** (Гродно, Брест, Витебск) показывают дефицит представленности топ-позиций при наличии спроса — потенциал роста без увеличения производства
